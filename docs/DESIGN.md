# Дизайн

## Концепция

Современный минимализм с редакционным характером: крупная типографика, тонкие линии-разделители, асимметричные раскладки и свободное пространство. Повторяющихся скруглённых карточек нет, каталог треков оформлен как нумерованный список со строками.

## Палитра (`:root` в `style.css`)

| Токен | Значение | Использование |
|---|---|---|
| `--bg-color` | `#f9f7f2` | Основной фон |
| `--bg-alt` | `#f0eadc` | Фон секции About |
| `--surface` | `#fffdf8` | Панель плеера |
| `--text-color` | `#3b352f` | Основной текст |
| `--text-muted` | `#6a6158` | Второстепенный текст |
| `--accent-green` | `#2f4a3a` | Заголовки, кнопки, фокус |
| `--earthy-brown` | `#6c5d4f` | Номера, подписи |

Контраст пар цветов вручную не измерялся. Его нужно проверить инструментом (см. `DEVELOPMENT.md`).

## Типографика

- Заголовки и подписи: Comfortaa (700).
- Основной текст: Fredoka (300, 500).
- Размеры крупных заголовков задаются через `clamp()`.

## Фон

Оригинал `files/Elegant beige waves on soft background.png` используется как фон секции Hero. Файл не изменяется и не конвертируется.

## Раскладка

- Mobile-first: базовые стили для 320 px, расширения на `min-width: 48em` и `64em`.
- Контейнер `.wrap` до 72rem.
- На широких экранах плеер закреплён слева (`position: sticky`), список треков справа.

## Доступность

- Ссылка «Skip to content», семантические секции с `aria-labelledby`.
- `:focus-visible` с контрастной обводкой.
- Кнопки плеера не меньше 44 px.
- `prefers-reduced-motion` отключает плавный скролл и сокращает переходы.
