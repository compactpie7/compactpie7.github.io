# Разработка

Общие правила описаны в `AGENTS.md`. Здесь — практическое руководство.

## Локальный запуск

Из корня проекта выполните `python -m http.server 8000` и откройте http://localhost:8000/. Прямое открытие `index.html` через `file://` не подходит: браузеры блокируют ES-модули.

## Стиль кода

- Отступ 4 пробела.
- Классы в нижнем регистре через дефис.
- Цвета и размеры — через CSS-переменные в `:root`.
- Текст в DOM выводить через `textContent`, не `innerHTML`.
- Пути относительные, регистр имён файлов должен совпадать с реальным.

## Как добавить трек

1. Положить файл в `files/` (оригиналы не переименовывать и не удалять).
2. Скопировать блок `<li class="track">` в `index.html`.
3. Указать `data-src` (пробелы как `%20`), `data-title`, номер, название и описание. Пути в `<source>` и ссылке на файл должны совпадать.

## Чек-лист ручной проверки

Статус: автоматических тестов нет, проверка в браузерах ещё не выполнялась.

- [ ] Страница открывается по локальному серверу, консоль без ошибок.
- [ ] Нет горизонтальной прокрутки на ширинах 320, 375, 768, 1024, 1440 px.
- [ ] Музыка не начинается сама, до нажатия Play аудио не загружается (вкладка Network).
- [ ] Play/Pause, Next/Previous работают для обоих треков.
- [ ] Перемотка мышью, пальцем и клавиатурой (стрелки, Home, End).
- [ ] Одновременно играет только один трек.
- [ ] Ошибка загрузки показывает сообщение (временно изменить путь в `data-src`).
- [ ] Отключённый JavaScript: видны нативные плееры и ссылки на файлы.
- [ ] Навигация клавишей Tab, видимый фокус, ссылка Skip to content.
- [ ] `prefers-reduced-motion`.
- [ ] Контраст текста (WCAG AA), масштаб 200%.
- [ ] Safari и iOS, Firefox, Chrome, Edge.
- [ ] Проверка регистра и пробелов в путях `files/`.
