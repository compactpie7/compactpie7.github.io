# Архитектура

## Общая схема

Статический сайт из одной страницы. Разметка, стили и поведение разделены:

- `index.html` — структура и контент, каталог треков записан прямо в HTML.
- `style.css` — единый файл стилей, разделённый комментариями-секциями.
- `js/` — три ES-модуля без зависимостей, подключаются одним тегом `<script type="module" src="js/main.js">`.

## Модули JavaScript

| Модуль | Ответственность |
|---|---|
| `js/main.js` | Находит элементы плеера и треки в DOM, создаёт `Player`, вызывает `initPlayerUi`, показывает кастомный плеер. |
| `js/player.js` | Класс `Player`: единственный `HTMLAudioElement`, список треков, состояния (`idle`, `loading`, `playing`, `paused`, `ended`, `error`), события `statechange`, `trackchange`, `timeupdate`, `durationchange`. |
| `js/player-ui.js` | Подписка на события `Player`, обновление кнопок, прогресса, времени, названия и статуса. Текст вставляется через `textContent`. |

## Плеер

- Аудиоэлемент один, он лежит в DOM (`index.html`, `data-player-audio`) с `preload="none"`. Перед выбором трека `preload` меняется на `metadata`. Одновременное воспроизведение исключено, так как источник один.
- Autoplay нет: `play()` вызывается только из обработчиков действий пользователя.
- Перемотка выполнена нативным `<input type="range">`, он работает с клавиатурой и касанием.
- Ошибки загрузки (`error` у аудио) и отказ `play()` переводят плеер в состояние `error` и выводят сообщение в `role="status"`.

## Деградация без JavaScript

Каждый трек в HTML содержит нативный `<audio controls preload="none">` и прямую ссылку на файл. Кастомный плеер скрыт атрибутом `hidden`. `main.js` показывает его и удаляет нативные плееры только после успешной инициализации, поэтому без JS (или при ошибке загрузки модуля) остаётся рабочий вариант.

## Пути к ресурсам

Все пути относительные. В именах файлов `files/` есть пробелы, поэтому в HTML и CSS они записаны как `%20`. Файлы не переименовываются. На GitHub Pages (Linux) регистр имён важен.

## Принятые решения и отклонённые альтернативы

| Решение | Почему | Отклонено |
|---|---|---|
| Один `style.css` | Одна страница, мало стилей | Разбиение на модули с `@import` (лишние запросы) |
| ES-модули без сборщика | Работают на GitHub Pages, нет зависимостей | Vite, webpack |
| Каталог в HTML | Работает без JS, индексируется | Рендер из JSON (имеет смысл при росте каталога) |
| Один общий `<audio>` | Исключает одновременное воспроизведение | Несколько независимых аудиоэлементов |
| Нативный range для перемотки | Доступность и касания «из коробки» | Самописный ползунок |

## Расширяемость

Чтобы добавить трек, нужно скопировать блок `<li class="track">` в `index.html` и указать `data-src` и `data-title`. Код JS менять не требуется.
